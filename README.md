Membership Reward System is a add-on page for items here where user can singup, login and retrieve their game data, redeem rewards with the available game points, the add-ons include following:

Signup : Register as new member to play the game
Login : Login to retrieve and save user game data (chances, points)
Reset password : Member can reset password via email
Redeem Rewards : Redeem rewards using game points
Redeem Code : Redeem rewards using promo code
Purchase points : Purchase game chances or points to continue game play (require third-party payment plugins)
Admin Dashboard : Admin access to view all members, user points, point package for purchase and transactions.
Admin Dashboard : Admin access to change and update game assets and settings.
Scoreboard : View top 10 score among all players.
HTML5 Gamble Games list with the latest version that are compatibility with this add-on:

Lucky Wheels – HTML5 Game, Version 1.5 and above
Lottery Numbers – HTML5 Game, Version 1.6 and above
Jungle Scratch – HTML5 Game, Version 1.2 and above
More games
NOTE: This add-ons DOES NOT include the original game but just additional pages.

How to use
1. Get the HTML5 Gamble Games that is compatible with this add-on from here
2. Copy and integrate the Membership Rewards System files
3. Setup server and database (PHP MySQL)
4. Membership and rewards system is ready for the game.
5. Setup admin dashboard if you wish to view all records for members, user points, point package for purchase and transactions.
6. Enable scoreboard to view top score among all players.

*Server requirements:
– PHP version 7.4 – 8.3
– PHP with MySQLi extension activated

Features
Register as member to play all the gamble game with single account.
Login to save and retrieve user game data (chances, points, rewards).
Forgot password can be reset via email.
Facebook Connect to play without registration.
Game result load and generate from server.
Redeem rewards item using available game points.
Redeem rewards using promo code.
Global game chances and points for all games.
Access all gamble games in member section.
Purchase game chances or points to continue game play (require third-party payment plugins)
Scoreboard to view top 10 score among all players (daily, weekly, monthly high score).
Admin access to view all members, user points, rewards item.
Manage rewards item name and point via admin.
Manage update promo code for redeem via admin.
Manage update products for purchase via admin.
Change and update game assets and settings via admin.
Datas can be export via admin (CSV, EXCEL, PDF, PRINT)
